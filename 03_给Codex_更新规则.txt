我的新规则/修正规则：
【在这里粘贴你的新规则】

请严格按 AGENTS.md 的 Rule Update Protocol 执行：
1. 判断这条规则应该归入哪个最小范围的 Skill / rule 文件。
2. 如果与旧规则冲突，以这次最新明确规则为准，替换或废弃旧规则，不保留互相矛盾的版本。
3. 不要把同一规则重复复制到很多文件。
4. 如果规则影响确定性程序行为，修改共享通用代码，禁止建立公司专用代码。
5. 增加或更新相应回归测试。
6. 更新 CHANGELOG.md。
7. 按语义化版本规则更新 VERSION：
   - 小修复/规则修正：patch，例如 2.2.0 -> 2.2.1
   - 新增兼容功能：minor，例如 2.2.x -> 2.3.0
   - 重大不兼容变化：major
8. 运行全部相关测试。
9. 测试通过后提交 Git。
10. 推送到当前 GitHub main 分支。
11. 不修改 references 中真实数据库文件。

最后告诉我：
- 修改了哪些文件
- 旧规则是否被替换
- 新增/修改了哪些测试
- 测试结果
- VERSION 从多少变为多少
- commit 信息
- 是否已推送 GitHub
