# User Rule Updates

Use this file as a short intake log for newly supplied rules before they are consolidated into the correct permanent rule/skill file.

## Rule update protocol
1. Latest explicit user rule overrides conflicting older rules.
2. Update the smallest appropriate permanent rule/skill file.
3. Do not duplicate the same rule across many files.
4. If deterministic behavior changes, add/update regression tests.
5. Record the change in CHANGELOG.md.
6. Do not create company-specific code to implement a general rule.
